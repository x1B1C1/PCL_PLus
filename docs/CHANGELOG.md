# 更新日志

本文件按版本倒序记录 PCL_Plus 的变化。正式线（`main`）版本带 `R` 后缀，测试线（`beta`）带 `-beta`。

## 3.0.1（正式线）

液态玻璃外观的第一个正式版本，相对 2.6.3 主要是界面与发布体系的变化。

### 外观
- 顶栏、侧栏、卡片、按钮支持液态玻璃材质（边缘折射、色散、内侧高光），可在「设置 → 个性化 → 液态玻璃」开关。
- 账号区域从半透明白底改为真正的磨砂玻璃层，与卡片、侧栏保持同一套材质。
- 切换壁纸后玻璃会按壁纸主色重新染色。
- 修复内置壁纸不参与自动取色：取不到主色时改用随包内置壁纸同步解码兜底，不再一直停在主题默认色相。

### 个性化
- 背景卡片新增「空」按钮：一键停用壁纸，只保留主题底色。

### 发布
- 正式版与测试版使用不同的资产名（`PCL_Plus_Release_x64.exe` / `PCL_Plus_Beta_x64.exe`）。
- 新增 GitHub Actions：`Build (CI)` 校验编译，`Release publish` 手动发版。

## 3.0.1-Beta3（测试线）

在 3.0.1 的基础上调整玻璃默认值与窗口裁剪。

### 修复
- 开启玻璃后窗口四边被切掉一圈：根因是根容器内缩 10px 后 `SetWindowRgn` 按缩进矩形裁剪，现已取消内缩。
- 窗口圆角与 `WindowChrome` 对齐为 12。
- 玻璃默认折射壁纸而不是采集桌面，避免采样到桌面窗口后整体偏色。
- 修复内置壁纸取不到主色（内置图改为 `CacheOption.OnLoad` 同步解码，并在取不到时兜底）。

### 个性化
- 背景卡片新增「空」按钮；账号区域改为磨砂玻璃。

### 界面
- 主页删除「上次游玩」卡：启动入口统一留在左侧，主页只显示状态类信息。
- 主页删除「启动时检查模组依赖」勾选框，迁移到「实例设置 → 依赖检查」页，与依赖报告放在一起。
- 工具页新增「陶瓦联机」板块：整份设置卡从「设置 → 杂项」移入，程序路径、邀请码、房间操作与状态显示原样保留。
- 工具页移除「正版皮肤下载」「瞅眼服务器」「成就生成器」「皮肤头像生成器」四个板块；百宝箱与自定义文件下载保持原样。

## 3.0.1-Beta2（测试线）

3.0 系列的第二个测试版。液态玻璃改用 `bedkillerspacex-boop` 的完整移植（PR #2），替换掉 Beta1 里的自研版本。

### 液态玻璃

- **材质参数化**：新增亮度、卡片亮度、卡片不透明度、扩散、边缘锐度、采样质量、采样帧率、色调缩放、动效开关等调节项，可在 设置 → 个性化 → 液态玻璃 里逐项微调。
- **按钮也玻璃化**：`MyButton`、`MyListItem`、`MyRadioButton`、`MyComboBox`、`MyTextBox`、`MyCard` 六个控件补齐玻璃分部，按钮带指针跟随与按压高光。
- **桌面采集**：DXGI 桌面复制 + 窗口裁剪，玻璃可以真正折射窗口后面的桌面内容。
- **回归测试**：`PCL.Core.Test/UI/` 新增 16 个测试文件，覆盖材质计算、采样形状、窗口帧、桌面采集与配置解析。

### 其他

- 合入 world backup 源码（此前被 `.gitignore` 的 `Backup*/` 规则误排除，导致干净检出编译失败）。

## 2.6.3（正式线）

正式线第一次完整包含测试线 2.5 / 2.6 系列的功能。相对 2.1.1R：

### 外观

- **主题色跟随壁纸**：启动时从当前壁纸取主色相（24 个 15° 色相桶投票，不把不同颜色平均成中间色），标题栏、卡片、按钮、进度条一起变色；可在设置 → 个性化里关闭
- **背景磨砂**：背景模糊默认 10 像素
- **亚克力材质**：顶部栏、卡片、左侧账号区域半透明，衬出背后的壁纸
- **LF 色板**：以 `#00B7FF` 为主色的浅色主题，深浅两套灰度按同一亮度阶梯生成
- **UI 设计系统 v1.5**：卡片圆角 11、控件圆角 8、控件高 30，ToolTip 与右键菜单统一圆角

### 更新

- **更新提示改为独立窗口**：黑底白字、蓝色按钮，显示「当前版本 → 新版本」与更新日志
- **更新说明窗口**：版本号用固定蓝色，不随主题变化
- **更新通道简化为两档**（稳定版 / 测试版），并新增「测试 OTA」开关，可在正式版里验证整条升级链路
- 修复正式版本号带 `R` 时检查更新报 `ArgumentException: Invalid semantic version format` 的问题

### 游戏实例

- 存档备份、环境还原点、创建测试副本、整合包更新（事务回滚）
- 加载器匹配核查、启动前模组依赖检查（缺失前置可一键打开模组管理）
- 按版本记忆按键 / 鼠标 / 视角设置
- CurseForge 地图自动归档到存档目录下的 `PCLLFWorldDownload`

### 其他

- 「加入群」入口移到启动日志上方，主页不再重复一份
- 内置 Terracotta 联机与 Lunar 平台入口

## 2.0R（正式线）

这一版把界面整体换成 PCL Living Fork 的配色体系，并补齐实例管理能力。

**主题与外观**

- 浅色按 LF 的 HSL 公式计算 `ColorBrush1..8`，深色使用 LF 的固定深色表
- 每个内置主题按自身色相生成配色（龙猫蓝 210 / 甜柠青 180 / 小草绿 130 / 菠萝黄 75 / 橡木棕 35 / 玄素黑 225 低饱和 / 滑稽彩 290 / 铁杆粉 345 / 神秘紫 285 / 欧皇彩随机 / 秋仪金 50 / 活跃橙 25 / 跳票红 5 / 极客蓝 230）
- 补齐 26 条语义角色色（卡片、对话框、弹层、次要文字、强调文字、红蓝黄绿提示、阴影），深浅两套
- 标题栏改为三点渐变，两端色相各偏 `Delta-90`
- 图标换成 Blue Crystal 六边形（10 个尺寸）
- 启动日志改为只读文本框卡片；新增启动选项与「上次游玩」卡片；社区卡只保留加群入口
- 首页底部按钮改为「版本选择 / 版本设置」
- 新增更新说明窗口，版本变化后首次启动弹出一次

**实例管理**

- 新增「备份」页：手动/自动备份、保留 1–50 份、恢复与移除，恢复前自动留档
- 新增「还原点」页：内容寻址存储，覆盖模组/配置/脚本/资源包与版本文件，启动前自动打点
- 实例总览新增测试副本：白名单复制版本与环境目录，记录来源
- 新增「整合包更新」页：`.mrpack` / CurseForge 包比对新增/更新/保留，应用失败整体回滚
- 新增「依赖」页：列出缺失前置与可启用的禁用模组
- 模组管理器增加加载器匹配提示

**启动与游戏**

- 启动流程加入前置依赖检查（可选打开模组管理 / 仍然启动 / 取消）
- 个人游戏习惯在版本间同步，单版本可覆盖
- CurseForge 地图统一解压到 `saves\PCLLFWorldDownload`

**协议**

- 许可证更换为《PCL 分发有限许可》与《PCL 存储库合理使用指南》，关于页首位显示原作者署名与赞助入口
