# PCL_Plus 液态玻璃移植

来源：`askbbtsk/pcl-lite` PR #17，固定提交
`ad169353124a96b7bb6ca5a2c98b64cfbc6909fb`。
移植包含该提交的最终实现及其已有的玻璃渲染、桌面采集和主题资源依赖，
没有移植 Lite 的插件系统、命令面板、版本号或发布说明。

## 使用与设置

在「设置 → 个性化」的液态玻璃卡片开启。新旧用户首次使用均默认关闭；
开启时显示性能说明，实时桌面折射另需确认。只开启玻璃时以窗口背景和壁纸为采样源。

性能预设、自定义、恢复推荐参数与来源提交一致。滑块均为整数、步进 1：

| 设置 | 可选范围 | 初始值或规则 |
| --- | --- | --- |
| 磨砂 | 0–24 DIP | 8 |
| 折射 | 0–200% | 100%（内部强度 0.05） |
| 动画帧率 | 30–240 FPS / 不限制 | 60 FPS |
| 桌面采样帧率 | 30–240 FPS / 不限制 | 初始跟随动画帧率 |
| 桌面采样质量 | 25–100% | 100% |
| 模糊 | 0–32 DIP | 跟随预设 |
| 色散、高光 | 0–100% | 跟随预设 |
| 漫反射 | 0–50% | 浅色 17%、深色 14% |
| 边缘锐度、染色 | 0–100% | 90%、100% |
| 卡片透明度 | 0–100% | 浅色 80%、深色 77% |
| 玻璃、卡片明暗度 | -50–50 | 均为 0 |

预设默认为标准档（索引 1）。调整单项后切换到自定义并保留其他参数；
恢复推荐参数使用标准档，并重置两类明暗度。动效开关也随预设或用户设置保存。
窗口透明度在玻璃模式仅调整底图及壁纸，不使文字和玻璃一起变透明。

## Plus 适配与兼容

- `Config.Preference.TahoeGlass` 的 21 项持久化键均以 `UiTahoeGlass` 开头。
  不读取、不覆盖旧 `UiLiquidGlass*` 参数；旧覆盖层停止渲染，旧数据保留供旧版本回退。
- 接入 Plus 的目录命名空间、现有页面导航、主题刷新和窗口生命周期。
  标题栏、侧栏、窗口按钮使用独立采样层；文字与输入仍由原控件处理。
- 移植按钮、卡片、列表项、导航单选、下拉框、文本框的材质适配；
  关闭后恢复 Plus 原有圆角、边框和窗口样式。
- 保留高对比度及不支持着色器时的回退。桌面采集使用来源提交的 Magnifier 后端；
  采集协调器管理隐藏、卸载、过期回调、显示变化和故障恢复。
- 玻璃依赖的主题资源层保留自定义模板覆盖。版本范围校验从 Lite SDK 提取为
  `ThemeVersionRange`，没有新增插件 SDK 引用。

着色器源码及编译产物位于 `Plain Craft Launcher 2/Resources/LiquidGlass/`。
`Compile.ps1` 使用 Windows SDK fxc，缺少 fxc 时使用系统 `d3dcompiler_47.dll`。
目标为 `ps_3_0/main`。第三方来源与许可见同目录 `NOTICE.txt`。
